Динамическое программирование применяется к задачам оптимизации. В них возможно некоторое количество верных решений. При этом среди всего пула решений существуют *оптимальные решение*. 

Задача *динамического программирования* делится на 4 этапа:
1. Описание структуры оптимального решения
2. Рекурсивное определение задачи
3. Вычисление задачи методом восходящего анализа (от маленького к большому)
4. Составление оптимального решения

Шаг №4 может опускаться, если нужен ответ без уточнений его получения.

# Задача двух конвейеров

## Задача

Даны два конвейера, каждый из которых выполняет одинаковые этапы сборки за фиксированное время. Т.к. этапы взаимозаменяемые, то за определенное время процесс сборки можно переложить с одного конвейера на другой. Необходимо определить минимальное время, за которое будет изготовлен объект.

## Шаг №1. Описание структуры оптимального решения

Пусть $S_{i, n}$ - минимальное время, необходимое для попадания на $n$-ый этап $i$-го конвейера.
На первый этап одного из конвейеров можно попасть за $e_1$ или $e_2$, т.е. $S_{1,1}=e_1 + a_{1, 1}$ и $S_{2, 1} = e_2 + a_{2, 1}$. 

На этапы со 2-го по $n$-ый можно попасть либо с того же конвейера, либо с другого конвейера, при этом будет затрачено время $t_{j, 1}$ для перекладывания. Получается $S_{i, 2} = \min(S_{i,1}, S_{j, 1} + t_{j, 1}) + a_{i, 2}$. Из этого получается *оптимальное решение* задачи, включающее в себя *оптимальное решение подзадач*.


Прийти в `finish`можно с двух конвейеров, причём время перехода с 1-го конвейера равно $f_1$, а со второго $f_2$. Пусть всего $n$ этапов, тогда время за которое будет достигнут `finish` будет  $S_{1, n} + f_1$ и $S_{2,n} + f_2$, где $S_{i, n}$ - время, за которое был достигнут $n$-ый этап.

## Шаг №2. Рекурсивное определение задачи

Из предыдущего шага была получена формула, соответствующая и вычислению времени, необходимое для достижения и выполнения этапа на любом из конвейеров: 
- $S_{i, n} = \min(S_{i,n-1}, S_{j, n-1} + t_{j, n-1}) + a_{i, n}$

Итого можно получить рекуррентные соотношения:

$$S_{1, j} = 
\begin{cases}
e_1 + a_{1, 1} \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \text{при } j = 1 \\
\min(S_{1,j-1}, S_{2, j-1} + t_{2, j-1}) + a_{1, j} \quad \text{при } j \geq 2
\end{cases}
$$
$$S_{2, j} = 
\begin{cases}
e_2 + a_{2, 1} \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \text{при } j = 1 \\
\min(S_{2,j-1}, S_{1, j-1} + t_{1, j-1}) + a_{2, j} \quad \text{при } j \geq 2
\end{cases}
$$


Итоговым решением задачи

Очевидно, что попасть на $n$-ый этап $i$-го конвейера можно с $n-1$ шага этого или другого конвейера. К тому же на каждом этапе выполняется работа за время $a_{i, n}$. Тогда время после которого будет достигнут и выполнен $n$-ый шаг может вычислять 2-мя способами:
- $S_{i, n} = S_{i, n-1} + a_{i, n}$, если этап выполняется на том же конвейере
- $S_{i, n} = S_{j, n-1} + t_{n-1} + a_{i, n}$, если этап выполняется на другом конвейере

## Шаг №3. Вычисление задачи методом восходящего анализа

Если решать задачу рекурсивно, то сложность составит $O(2^{n})$. Поэтому её можно решать методом восходящего анализа:
- Начать с положения `start`
- Итерироваться по этапам
	- На каждой итерации вычислять $S_{i, j}$ у каждого конвейера
- При достижения положения $n$-го этапа вычисляем ответ формулой $\min(S_{1, n} + f_1, S_{2, n} + f_2)$. 

В случае, если вычислять сам путь *оптимального решение* не нужно, то на этом шаге алогоритм заканчивается, иначе переходим к Шагу №4.

## Шаг №4. Составление оптимального решения

После получения итогового *оптимального решения* можно восстановить путь, по которому было получено это решение:
- Из финиша идём в вершину конвейера, откуда был получен минимум
- Из вершины:
	- если оба пути дают одинаковый результата, то фиксированно устанавливаем правило, куда идём во всех таких случаях и переходим
	- если результаты разные, то идём в ту вершину, которая даёт минимально время
- При достижения стартовой позиции будет получен *оптимальный путь*, по которому быстрее всего собирать объект на конвейере.

# LCS (longest common subsequence - наибольшая общая подпоследовательность) 

Пусть $X = \{A, B, C, B, D, A, B \}$, а $Z = \{ B, C, D, B \}$. Тогда последовательность $Z$ является подпоследовательностью $X$, причем ей соответствует последовательность индексов $\{ 2, 3, 5, 7 \}$.

Последовательность $Z$ является общей подпоследовательностью последовательностей $X$ и $Y$, если $Z$ подпоследовательность и $X$, и $Y$ одновременно. Пусть $Y = \{ B, D, C, A, B, A \}$. Тогда наибольшая общая подспоследовательность $X$ и $Y$ - $\{ B, D, A, B \}$.

В задаче поиска LCS даны две последовательности. Необходимо найти их общую подпоследовательность максимальной длины.

## Этап 1. Описание структуры оптимального решения

Пусть даны последовательности $X = \{ x_1, x_2, \dots, x_{n-1}, x_n  \}$ и $Y = \{y_1, y_2, \dots, y_{m-1}, y_{m} \}$, а $R = \{ r_1, r_2, \dots, r_{k-1}, r_k \}$ их наибольшая общая подпоследовательность.

Тогда возможны следующие ситуации:
- $x_n = y_m$, тогда $x_n = y_m = r_k$, а $\{r_1, r_2, \dots, r_{k-1} \} = \text{LCS} ( \{ x_1, x_2, \dots, x_{n-1} \}, \{y_1, y_2, \dots, y_{m-1} \} )$.
- $x_n \neq y_m$ и $x_n \neq r_k$, тогда $R = \text{LCS} ( \{ x_1, x_2, \dots, x_{n-1} \}, Y)$
- $x_n \neq y_m$ и $y_m \neq r_k$, тогда $R = \text{LCS} \left( X, \{ y_1, y_2, \dots, y_{m-1} \} \right)$

Докажем эти утверждения:

- $x_n = y_m = r_k$
Пусть $x_n = y_m$ и $x_n \neq r_k$, тогда в конец $R$ можно дописать $x_n = y_m = r_{k+1}$. Получается найдена общая подпоследовательность $R$ длины $k+1$, что противоречит определению "$R$ - наибольшая общая подпоследовательность". 
Допустим $x_n = y_m = r_k$ выполняется и существует подпоследовательность $W = \text{LCS} ( \{ x_1, x_2, \dots, x_{n-1} \}, \{y_1, y_2, \dots, y_{m-1} \} )$, длина которой больше $k-1$. В таком случае дописав к этой подпоследовательности элемент $x_n = y_m$ получается общая подпоследовательность, длина которой больше $k$, что противоречит определению $R$. **ЧТД!**
- $R = \text{LCS} ( \{ x_1, x_2, \dots, x_{n-1} \}, Y)$
Пусть $x_n \neq y_m$ и $x_n \neq r_k$. Также существует $W = \text{LCS} ( \{ x_1, x_2, \dots, x_{n-1} \}, Y)$ длины больше $k$, то $W = \text{LCS} (X, Y)$. Тогда $R$ не является наибольшей общей подпоследовательностью - противоречие! **ЧТД!**
- $R = \text{LCS} \left( X, \{ y_1, y_2, \dots, y_{m-1} \} \right)$

Получается, что $\text{LCS}(X, Y)$ содержит в себе $\text{LCS}$ их префиксов. Следовательно у задачи существует оптимальное решение.
